# jobtracker-api
A backend API for tracking job applications. Built to learn modern Python backend (FastAPI, async, testing, docker)

 ## Stack        

  - **FastAPI** — modern async Python web framework
  - **SQLAlchemy 2.x** + **SQLite** (Postgres later) — database & ORM
  - **Pydantic** — data validation                                                                  
  - **pytest** — testing                                                                            
  - **Docker** — containerization

## Status       

🚧 Work in progress. Building over 8 weeks to deepen practical Python skills (async, OOP, testing,
   deployment).

## Project Goals                                                                                  
   
 - [ ] Core CRUD endpoints for applications, companies, interviews                                 
 - [ ] Authentication (JWT)
 - [ ] Background jobs for deadline reminders (async)                                              
 - [ ] Statistics & reporting endpoints
 - [ ] Full test coverage with pytest                                                              
 - [ ] Docker + CI/CD
 - [ ] Deployed to Railway/Fly.io
